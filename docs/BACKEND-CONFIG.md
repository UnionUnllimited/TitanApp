# Удалённые настройки iOS-приложения (titan-config)

Для разработчика бэкенда и панели. Через эти настройки панель включает и выключает части
iOS-приложения без новой сборки: оплату, объявления, техработы, обновления, поведение «Авто» и
списка направлений, пороги «дорог», Live Activity и другое. Здесь описана только сторона
приложения (`ios/TitanVPS/RemoteConfig.swift`); как панель хранит и редактирует настройки, решает
бэкенд.

Главное правило: **любое поле можно не присылать**. Чего нет — работает как в сборке без настроек.
Пустой объект `{}` возвращает всё к поведению по умолчанию.

## Как доставить

Настройки приходят в заголовках ответа **сервера подписки** — того же ответа, в котором приходят
направления (в Remnawave: Настройки подписки → Дополнительные заголовки ответа; имена заголовков
без учёта регистра). Отдельный адрес в коде приложения не нужен.

| Заголовок | Что в нём | Когда удобен |
|---|---|---|
| `titan-config` | JSON настроек в base64 (обычный или URL-safe, с `=` в конце или без; можно с префиксом `base64:`). Приложение примет и JSON как есть, если он начинается с `{` и состоит из ASCII | небольшие настройки: заголовок ответа обычно ограничен 4–8 КБ |
| `titan-config-url` | https-адрес, по которому приложение само скачает JSON | всё остальное; настройки меняются без изменения подписки |

- Если пришли оба, главный `titan-config-url`; `titan-config` тогда не используется, даже если по
  ссылке ничего не получилось.
- Если не пришёл ни один, действуют последние полученные настройки (они сохранены на устройстве).
  Выключить настройку — прислать её с другим значением или прислать `{}`; убрать заголовки
  недостаточно.

Запрос по `titan-config-url` — `GET` с таймаутом 10 с и теми же заголовками, что у запроса
подписки:

```
User-Agent: Titan(IOS/<версия приложения>)
Accept: application/json
x-hwid: <идентификатор Titan на этом устройстве>
x-device-os: iOS
x-ver-os: <версия iOS>
x-device-model: Apple <модель, например iPhone16,2>
If-None-Match: <ETag прошлого ответа по этому же адресу, если был>
```

- Ответ `200` с JSON в теле (`Content-Type` не проверяется) — новые настройки; заголовок `ETag`
  приложение запомнит и пришлёт в следующий раз.
- Ответ `304 Not Modified` — настройки не менялись.
- Перенаправления допустимы, но конечный адрес должен быть https.
- Сам ключ подписки приложение в этот запрос не добавляет. Если серверу нужно знать, чей это
  запрос, ссылку можно выдавать своей для каждой подписки (её присылает сервер подписки).

## Когда приложение обновляет настройки

- При каждой загрузке подписки: запуск приложения, возвращение в него через 30 минут, «потянуть,
  чтобы обновить», кнопки «Обновить проездной», ввод кода проездного, ссылки `titanvps://`.
- По `titan-config-url` ещё и при каждом открытии приложения, если с последнего ответа по ссылке
  прошло 15 минут или больше.
- Ничего не запрашивается до того, как пользователь принял «Конфиденциальность», и без кода
  проездного: настройки приходят только вместе с подпиской.
- Настройки хранятся на устройстве (`UserDefaults`, ключ `titan.remoteConfig`) и действуют с
  запуска, без сети. Выход из аккаунта их не стирает: это настройки приложения, а не ключа.

## Ошибки

- Не JSON, не объект, больше 64 КБ, не https, ответ не 2xx и не 304, нет связи — приложение
  ничего не меняет, действуют прежние настройки. Приложение от этого не падает.
- Поле не того типа (строка вместо числа, объект вместо `true`) читается так, будто его нет;
  остальные поля действуют.
- Неизвестные поля и разделы пропускаются: новые поля можно добавлять в панель заранее.
- `version` — номер схемы; эта сборка читает схему `1`. Сборка, получившая схему новее, применяет
  те поля, которые знает.
- Адреса (`url`, `purchaseEndpoint`) — только `https://` с хостом; другие пропускаются.
- `purchaseEndpoint` — ещё и только на хостах подписки (`Config.hosts` в `ios/TitanVPS/Subscription.swift`):
  с каждой покупкой приложение отправляет туда код проездного. Адрес на другом хосте приложение не берёт
  (в Техническом режиме — «отклонён»), покупки ждут.

Проверить, что пришло и как применилось, можно в Техническом режиме приложения: карточка
«Удалённые настройки» (откуда пришли и когда, ETag, значение каждого переключателя).

## Не секрет

Настройки видит любой, у кого есть ссылка подписки: их можно получить запросом к серверу
подписки или прочитать на устройстве. **Не кладите в них токены, ключи, пароли, адреса админки и
панели.** Всё в них — публичные переключатели и тексты.

App Review (правило 2.3.1) считает функции, скрытые на время проверки и включённые после неё,
поводом для удаления приложения, поэтому оплата и другие функции должны быть в проверяемой сборке
такими, какими будут работать; эти переключатели — для эксплуатации: сбои, постепенное
включение, объявления.

## Тексты

`announce.text`, `maintenance.text` и `update.text` приложение показывает как есть. Пишите их
словами темы «Маршрут» (`docs/HANDOFF.md`, «Тема «Маршрут» на iOS»): без «VPN», «сервер»,
«подписка» (на экране — «проездной»), «трафик», «ключ» (на экране — «код проездного»),
«подключ…», «блокировк…», «обход» (на экране — «объезд»), «пинг», «IP» и других слов из правила
владельца. Например: «Объезды МТС работают с перебоями — попробуйте «Авто»», а не «Обход
блокировок МТС не подключается».

## Схема, версия 1

Все поля необязательные. «По умолчанию» — что делает приложение, если поля нет.

### `payments` — оплата (сборка с оплатой, `TITAN_PAYMENTS`)

| Поле | Тип | По умолчанию | Что на экране |
|---|---|---|---|
| `enabled` | bool | `true` | `false` — всё про оплату скрыто, как в сборке без неё: «Продлить проездной», «Добавить ГБ», «Личный кабинет», «Расширенные функции», «Продлить» у «Проездной закончился», «Нет проездного?» на экране ввода кода, бот в «Устройствах» и «О приложении». Вместо этого — «Поддержка». Напоминания — без призыва продлить |
| `appStore` | bool | `true` | `false` — без покупок App Store: в «Тарифах» нет карточек App Store, на экране ввода кода нет «Нет проездного?» («Проездной через App Store», «Восстановить покупки», «Ввести код предложения»), в «Конфиденциальности» нет пункта о покупках |
| `otherMethods` | bool | `true` | `false` — без оплаты мимо App Store: нет «Другие методы» в «Тарифах», вкладки «Тарифы» в кабинете, «Где взять проездной» с ботом на экране ввода кода (вместо неё — «Поддержка»), «Открыть сайт», кнопки «Telegram-бот» в «О приложении» |
| `cabinet` | bool | `true` | `false` — нет «Личного кабинета» и карточки «В личном кабинете» на вкладке «Проездной» |
| `purchaseEndpoint` | string (https, хост подписки) | нет | куда приложение отправляет покупки App Store (`docs/BACKEND-APPSTORE.md`); только на одном из хостов подписки (`Config.hosts`), другой хост — как будто адреса нет. Пока его нет, покупки ждут и не завершаются; когда он приходит впервые, ждущие уходят сразу. Работает и при `enabled: false`: продления, оплаченные раньше, всё равно доходят |

Если и `appStore`, и `otherMethods` выключены, кнопок продления нет нигде.

### `announce` — объявление на «Маршруте»

| Поле | Тип | По умолчанию | Что на экране |
|---|---|---|---|
| `text` | string | нет | текст карточки над заголовком «Маршрута». Без текста карточки нет |
| `id` | string | сам текст | закрытое объявление с тем же `id` больше не показывается. Новый `id` (или новый текст без `id`) — снова видно |
| `level` | `"info"` \| `"warning"` | `"info"` | `info` — на светло-синей подложке, `warning` — оранжевая карточка с белым текстом |
| `url` | string (https) | нет | нажатие на карточку открывает ссылку (стрелка справа) |
| `dismissible` | bool | `true` | `false` — без крестика, карточка видна, пока объявление в настройках |

### `maintenance` — техработы

| Поле | Тип | По умолчанию | Что на экране |
|---|---|---|---|
| `enabled` | bool | `false` | `true` — оранжевая строка техработ на «Маршруте» у всех (та же, что при статусе аккаунта `MAINTENANCE`); нажатие открывает поддержку |
| `text` | string | «Идут технические работы. Маршруты могут не работать» | её текст |

Строка «Доступ к аккаунту закрыт» (статус `BLOCKED`) важнее и показывается вместо неё.

### `update` — обновления приложения

Номера сборок сравниваются с `CFBundleVersion` приложения — он виден в Профиле → «Версия» в
скобках. У сборок TestFlight это дата и время сборки по UTC в виде `ГГММДДЧЧММ` (например,
`2611201530` — 20 ноября 2026, 15:30); у неподписанного IPA из `ios.yml` — номер запуска CI.

| Поле | Тип | По умолчанию | Что на экране |
|---|---|---|---|
| `minBuild` | число | `0` | сборка с номером меньше — экран «Обновите Titan» вместо приложения, сразу при запуске (сохранённые настройки действуют и до «Конфиденциальности»): текст, «Обновить» (если есть `url`), «Остановиться» (если маршрут включён) и «Поддержка». «Сразу в путь» за этим экраном не подключает, ссылки `titanvps://` ждут. Подписка при этом обновляется как обычно: снизили `minBuild` — экран уходит, ждавшая ссылка открывается |
| `latestBuild` | число | `0` | сборка с номером меньше — карточка «Вышла новая версия Titan» на «Маршруте» с «Обновить» (если есть `url`); крестик скрывает её до следующего `latestBuild` |
| `url` | string (https) | нет | куда ведёт «Обновить»: страница в App Store или приглашение TestFlight |
| `text` | string | «Эта версия устарела. Установите новую, чтобы ехать дальше.» на экране «Обновите Titan»; на карточке — ничего | текст экрана и строка под «Вышла новая версия Titan» |

### `support` — поддержка

| Поле | Тип | По умолчанию | Что на экране |
|---|---|---|---|
| `url` | string (https) | заголовок подписки `support-url`, без него — бот | куда ведут все кнопки «Поддержка» (Маршрут, Проездной, Профиль, «О приложении», «Устройства», экран ввода кода, удаление аккаунта) |

### `routes` — «Авто» и список направлений

| Поле | Тип | По умолчанию | Что на экране |
|---|---|---|---|
| `auto` | `"best"` \| `"unlimited"` | `"best"` | на что ведёт карточка «Авто»: `best` — строка АВТО панели, без неё «⚡ Все направления», без неё первое обычное направление; `unlimited` — сначала «⚡ Все направления», потом АВТО. Меняется, когда маршрут стоит; в пути направление не меняется |
| `autoBypass` | bool | `true` | `false` — нет карточки «Авто · объезды», проверки ограниченного мобильного интернета и кнопки «Поехать объездом». Выбранные «Авто · объезды», пока стоим, переходят на «Авто»; в пути объезд остаётся как выбранный вручную |
| `manualList` | `"collapsed"` \| `"expanded"` \| `"hidden"` | `"collapsed"` | «Выбрать направление вручную»: `collapsed` — свёрнуто, пока пользователь не откроет (в широком окне на iPad, где у списка своя колонка, — открыто); `expanded` — открыто, пока пользователь не закроет (его выбор запоминается и важнее настройки); `hidden` — списка нет совсем, только «Авто» и «Авто · объезды» (уже выбранное вручную направление видно строкой «Вручную · …») |
| `bypassTab` | bool | `true` | `false` — в списке нет вкладки «Объезды» (объезды остаются доступны через «Авто · объезды») |
| `restrictedDetection` | bool | `true` | `false` — приложение не проверяет, ограничен ли мобильный интернет, и само не переходит на «Авто · объезды». Уже включённые проверкой «Авто · объезды», пока стоим, переходят на «Авто» |

### `roads` — слова о дорогах в списке

Пороги для «Проверить дороги» (холодная задержка через каждое направление, в миллисекундах).

| Поле | Тип | По умолчанию | Что на экране |
|---|---|---|---|
| `good` | число, 50–20000 | `500` | меньше — «свободно», зелёный |
| `calm` | число, больше `good`, до 60000 | `1500` (если `good` ≥ 1500 — `good` × 3) | меньше — «плотное движение», оранжевый; больше — «пробки», красный |

По этим же порогам «Авто · объезды» выбирает объезд не в «пробках». «Дорогу» на карточке поездки
(тёплая задержка, 120/300 мс) они не меняют.

### `features` — функции

| Поле | Тип | По умолчанию | Что на экране |
|---|---|---|---|
| `liveActivity` | bool | `true` | `false` — Live Activity и Dynamic Island не показываются (текущая закрывается), строки «Dynamic Island» в Профиле нет |
| `techMode` | bool | `true` | `false` — Технический режим не открыть (7 нажатий на «Версию» ничего не делают), включённый — выключается, его строки в Профиле нет |
| `animations` | bool | `true` | `false` — приложение ведёт себя как с «Уменьшением движения» в iOS: без пульса, бегущего пунктира, стрелки, параллакса, пружин и бликов — только плавные проявления |
| `tabSwipe` | bool | `true` | `false` — вкладки переключаются только панелью внизу, без свайпа по экрану |

## Примеры

Минимальный — только объявление:

```json
{"version": 1, "announce": {"id": "2026-11-20-mts", "text": "Объезды МТС работают с перебоями — попробуйте «Авто»", "level": "warning"}}
```

Тот же JSON в заголовке `titan-config` (base64 одной строкой; на Linux — `base64 -w0`, на macOS —
`base64`):

```
printf '%s' '{"version":1,"announce":{"id":"2026-11-20-mts","text":"…"}}' | base64 -w0
```

Полный, со всеми полями:

```json
{
  "version": 1,
  "payments": {
    "enabled": true,
    "appStore": true,
    "otherMethods": true,
    "cabinet": true,
    "purchaseEndpoint": "https://example.com/appstore/transactions"
  },
  "announce": {
    "id": "2026-11-20-news",
    "text": "Добавили новые направления в Европе",
    "level": "info",
    "url": "https://example.com/news",
    "dismissible": true
  },
  "maintenance": {"enabled": false, "text": "Идут технические работы до 18:00 по Москве"},
  "update": {
    "minBuild": 0,
    "latestBuild": 2611201530,
    "url": "https://apps.apple.com/app/id0000000000",
    "text": "Быстрее строим маршрут"
  },
  "support": {"url": "https://example.com/support"},
  "routes": {
    "auto": "best",
    "autoBypass": true,
    "manualList": "collapsed",
    "bypassTab": true,
    "restrictedDetection": true
  },
  "roads": {"good": 500, "calm": 1500},
  "features": {"liveActivity": true, "techMode": true, "animations": true, "tabSwipe": true}
}
```

(`example.com` и `id0000000000` — заглушки: подставьте свои адреса; `purchaseEndpoint` — на хосте подписки.)

Сбой: оплату временно убрать, у всех строка техработ, список направлений спрятать:

```json
{"version": 1, "payments": {"enabled": false}, "maintenance": {"enabled": true}, "routes": {"manualList": "hidden"}}
```

Обязательное обновление:

```json
{"version": 1, "update": {"minBuild": 2611201530, "url": "https://apps.apple.com/app/id0000000000"}}
```
